# Your first 28 learning days

Start date is intentionally unset: Day 1 is the day you choose to begin. This plan covers the beginning of CS50P, not the entire Python curriculum. Each week’s lecture is split across days; there are no invented timestamps. Open the official week page and stop at the named concept. Rewind and extend if needed.

Most study days budget 90 minutes: roughly 25 watching/reading, 45 building, 15 recall and 5 logging. Days 7/14/21 are 20-minute review/buffer days with optional rest. This is a sustainable starter plan; add exercises rather than extra courses if you have more time. Day 28 assesses understanding, not certificate progress.

## Day 1: Orientation and your first program

[Official resource](https://cs50.harvard.edu/python/weeks/0/) · 90 minutes.

- **Watch/read:** Open the course introduction and Functions/Variables lecture; watch until you can explain input and output.
- **Build:** Create learning-notes.md and hello.py; run it and record the command.
- **Recall:** Explain file, editor, terminal, program and output.

## After day 28

Continue CS50P libraries, unit tests, file I/O, regex and OOP; add Think Python for mutability, collections and additional practice. Then improve the tracker with JSON persistence and pytest, and introduce uv/Git through M02. The first month does not cover every M01 topic and must not be marked as full Python mastery.

The matching data/first-28-days.json can seed the later app. It contains resource links, task kinds, prerequisite IDs, time estimates and evidence requirements. Exact video chapters/timestamps can be added after you select the final lesson segments; they are not guessed here.
