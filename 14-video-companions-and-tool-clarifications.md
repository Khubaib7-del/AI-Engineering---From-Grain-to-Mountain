# Video companions and tool clarifications

The initial seven companions below are now supplemented by [the expanded video/paper guide](19-videos-and-agent-papers-in-order.md). The structured catalog contains 17 video/learning resources, including Karpathy and additional beginner/university options.

Use one primary course from `03-courses-in-order.md` and one targeted companion when a concept is confusing. Reproduce the exercise without the video before moving on; do not watch every overlapping playlist in parallel. These are strong options for your language preferences, not a claim that one teacher is universally best.

| Stage | Companion | How to use it |
|---|---|---|
| Classical ML, M07 | [CampusX 100 Days of ML](https://www.youtube.com/playlist?list=PLKnIA16_Rmvbr7zKYQuBfsVkjoLcJgxHH) | Intuition, preprocessing, algorithms; pair with the primary exercises. |
| ML alternative, M07 | [Krish Naik ML](https://www.youtube.com/playlist?list=PLZoTAELRMXVPBTrWtJkn3wWQxZkmTXGwe), [Hindi playlist](https://www.youtube.com/playlist?list=PLTDARY42LDV7WGmlzZtY-w9pemyPrKNUZ) | Choose an explanation for a specific difficult topic. |
| Deep learning, M08 | [CampusX deep learning](https://www.youtube.com/playlist?list=PLKnIA16_RmvYuZauWaPlRTC54KxSNLtNn) | Explain loss/backpropagation, then implement in PyTorch. |
| Retrieval, M11 | [CampusX RAG](https://www.youtube.com/playlist?list=PLKnIA16_Rmva0dRLWEHLznSHKbFD_RJfX) | Build a small corpus and compare retrieval quality. |
| Agents, M12 | [CampusX LangGraph](https://www.youtube.com/playlist?list=PLKnIA16_RmvYsvB8qkUQuJmJNuiCUJFPL) | Persistence, tools, streaming, approvals; add tests for failures. |
| Delivery, M16/M17 | [Krish Naik projects](https://www.youtube.com/playlist?list=PLZoTAELRMXVPS-dOaVbAux22vzqdgoGhG) | Pick one deployment project; update code against official docs. |

Verification, 2026-10-07: creator/channel and playlist search results reviewed; not every video watched or syllabus exhaustively audited. Playlist updates do not mean every lecture is new. Durable fundamentals can be older; fast-changing APIs need official documentation. Krish Naik's short MLOps playlist is not treated as a complete MLOps course.

Framework names are examples, not boundaries. The existing map covers 32 categories and 167 illustrative tools. Learn concepts first, implement one representative tool, then compare an alternative.

| Name | What it covers | Curriculum placement |
|---|---|---|
| LangChain | Model integrations, tools and application components | M10–M12 |
| LangGraph | Stateful workflows, persistence and agent control flow | M12 |
| LlamaIndex | Data ingestion, indexing and retrieval/application workflows | M11/M12 |
| Hugging Face | Model/dataset ecosystem and multiple distinct courses | M08–M15; not a synonym for LangChain |
| [Modular](https://www.modular.com/), [MAX/Mojo](https://github.com/modular/modular) | Inference/performance and systems programming | M17; different layer from agent orchestration |
| MLflow | Experiment tracking, model lifecycle and evaluation | M16 |
| QAI / WebML | Ambiguous names in the spoken request | Need an exact URL before identifying either; CrewAI is a separate known tool, not assumed to be QAI. |

The app bundles these companions, the primary courses, books and papers. It does not claim that clicking a resource proves mastery.
