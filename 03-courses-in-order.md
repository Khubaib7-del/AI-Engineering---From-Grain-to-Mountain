# Selected courses in prerequisite order

Selection date: 2026-10-07. These are my primary picks for this learner’s zero-to-engineering route, not a claim that one course is universally best. Selection favors official instructors, free material, exercises, clear prerequisites, and coverage. A living course plus current documentation is usually more reliable than searching only for a recent upload. English is the default because you accepted either English or Hindi. No certificates are required.

Use ONE main course for a stage. The optional resources fill specific gaps; do not watch competing complete playlists at the same time. The links below lead to official course pages or their author-linked recordings; I verified the course pages, not every individual video’s regional availability or every notebook’s execution.

## C01 — Python

**Primary:** [CS50’s Introduction to Programming with Python](https://cs50.harvard.edu/python/). [Official video playlist](https://www.youtube.com/playlist?list=PLhQjrBD2T3817j24-GogXmWqO5Q5vYy0V); [weekly syllabus](https://cs50.harvard.edu/python/weeks/).

**Before it:** No programming prerequisites; English lectures, shorts, problem sets.

**Do this:** Complete weeks 0–9 and your own final project. Pair with Think Python.

**Freshness/access:** Current course site; syntax is durable. Free study; certification optional.

**Used in:** M00/M01.

## C02 — Tools, shell, Git, packaging

**Primary:** [MIT Missing Semester 2026](https://missing.csail.mit.edu/). [Videos / syllabus](https://www.youtube.com/playlist?list=PLyzOVJj3bHQunmnnTXrNbZnBaCA-ieK4L).

**Before it:** Basic Python; English recordings and exercises.

**Do this:** Shell → environment → debugging → Git → shipping → code quality; revisit agentic coding after you can review code.

**Freshness/access:** Verified 2026 syllabus and playlist linked by authors.

**Used in:** M02.

## C03 — Computer science

**Primary:** [CS50x](https://cs50.harvard.edu/x/). [Videos / syllabus](https://cs50.harvard.edu/x/weeks/).

**Before it:** Beginner-friendly but demanding; English lectures and assignments.

**Do this:** After Python, study algorithms, memory, data structures and web/SQL foundations. For stronger CS preparation complete the whole course.

**Freshness/access:** Current OpenCourseWare; free study, optional certificate.

**Used in:** M03.

## C04 — SQL

**Primary:** [CS50 SQL](https://cs50.harvard.edu/sql/). [Videos / syllabus](https://cs50.harvard.edu/sql/weeks/).

**Before it:** Basic file/programming skills; English lectures.

**Do this:** Querying → relating → designing → writing → viewing → optimizing → scaling; final project.

**Freshness/access:** Current course site, exercises freely accessible.

**Used in:** M04.

## C05 — Linear algebra

**Primary:** [3Blue1Brown Essence of Linear Algebra](https://www.3blue1brown.com/topics/linear-algebra). [Videos / syllabus](https://www.3blue1brown.com/topics/linear-algebra).

**Before it:** School algebra first; English visual video series.

**Do this:** Vectors → span/basis → transformations → multiplication → dot product → eigenvectors. Add written exercises from MML; videos alone do not establish fluency.

**Freshness/access:** Foundational series; older recording remains suitable for these concepts.

**Used in:** M05.

## C06 — Probability

**Primary:** [Harvard Stat 110](https://projects.iq.harvard.edu/stat110/home). [Videos / syllabus](https://goo.gl/i7njSb).

**Before it:** Algebra and basic calculus; English lectures.

**Do this:** Counting/conditioning → Bayes → distributions → expectations → limit theorems; solve problems with the free probability book.

**Freshness/access:** Author site links videos and a free second-edition textbook; not a 2026 API course.

**Used in:** M06.

## C07 — ML and data analysis labs

**Primary:** [Statistical Learning with Python (ISLP)](https://www.statlearning.com/online-courses). [Videos / syllabus](https://www.youtube.com/playlist?list=PLoROMvodv4rNHU1-iPeDRH-J0cL-CrIda).

**Before it:** Python, arrays, basic probability; English.

**Do this:** Read ISLP chapters in order and do Python labs. Use theory videos linked on the same official page. Covers models, resampling, regularization, trees and unsupervised learning.

**Freshness/access:** Python edition 2023; stable ML foundations. Free author-linked videos/book; edX certificate unnecessary.

**Used in:** M04/M07/M19.

## C08 — Practical deep learning

**Primary:** [fast.ai Practical Deep Learning for Coders, part 1](https://course.fast.ai/). [Videos / syllabus](https://course.fast.ai/Lessons/lesson1.html).

**Before it:** Python and basic ML; English nine-lesson video course.

**Do this:** Complete nine lessons with your own dataset; then reimplement one training loop in raw PyTorch.

**Freshness/access:** Recorded 2022. Strong project-first foundation; use current PyTorch docs for API fixes, not old package pins blindly.

**Used in:** M08.

## C09 — NLP, transformers, adaptation

**Primary:** [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/en/chapter1/1). [Videos / syllabus](https://huggingface.co/learn/llm-course/en/chapter1/1).

**Before it:** Good Python and introductory DL, as the course states; English text with embedded videos.

**Do this:** Chapters 1–4 model basics, 5–8 data/tokenizers/tasks, 9 demos, 10–12 advanced training. Do labs; do not treat it as a pure YouTube playlist.

**Freshness/access:** Living official course; verify package compatibility when running.

**Used in:** M09/M13.

## C10 — LLM application engineering

**Primary:** [Full Stack LLM Bootcamp](https://fullstackdeeplearning.com/llm-bootcamp/). [Videos / syllabus](https://fullstackdeeplearning.com/llm-bootcamp/spring-2023/).

**Before it:** Python, plus ML/backend experience; English recorded lectures.

**Do this:** Foundations → prompting → augmented models → UX → LLMOps. Build a small extraction service alongside it.

**Freshness/access:** April 2023 recordings, explicitly dated by authors. Use for product/systems principles; update every SDK example through current docs.

**Used in:** M10.

## C11 — RAG

**Primary:** [LangChain RAG from Scratch](https://github.com/langchain-ai/rag-from-scratch). [Author-linked video playlist](https://www.youtube.com/playlist?list=PLfaIDFEXuae2LXbO1_PKyVJiQ23ZztA0x).

**Before it:** Python, model APIs and embeddings; English video series with notebooks.

**Do this:** Build a plain Python baseline first, then follow indexing/retrieval/query-transformation examples. Evaluate each addition.

**Freshness/access:** Earlier tutorials; current LangChain/LlamaIndex docs are the API authority. Does not imply framework is required.

**Used in:** M11/M20.

## C12 — Agent fundamentals

**Primary:** [Hugging Face Agents Course](https://huggingface.co/learn/agents-course/en/unit0/introduction). [Videos / syllabus](https://huggingface.co/learn/agents-course/en/unit0/introduction).

**Before it:** Python and LLM interfaces; text, videos and hands-on units.

**Do this:** Units 0–1 fundamentals; unit 2 smolagents/LangGraph/LlamaIndex; unit 3 use cases; unit 4 evaluated assignment.

**Freshness/access:** Living official course; prioritize one framework implementation after learning the plain loop.

**Used in:** M12.

## C13 — Agent orchestration depth

**Primary:** [LangChain Academy — Introduction to LangGraph, Python](https://academy.langchain.com/). [Videos / syllabus](https://academy.langchain.com/collections/build).

**Before it:** Python and agent basics; English video lessons.

**Do this:** Choose Introduction to LangGraph – Python in Build; focus state, persistence, streaming, review and recovery. One framework in depth.

**Freshness/access:** Official course content free; account may be needed. Certification paid and optional.

**Used in:** M12 optional depth.

## C14 — Model and research engineering

**Primary:** [Stanford CS336 Language Modeling from Scratch, 2026](https://cs336.stanford.edu/). [Videos / syllabus](https://www.youtube.com/watch?v=JuoVZkPBiKk&list=PLoROMvodv4rMqXOcazWaTUHhq-yembLCV).

**Before it:** Strong Python, PyTorch, calculus, probability, ML and systems; advanced English lectures.

**Do this:** Tokenizer/model/optimizer → training → systems → scaling → data → alignment. Do assignments at reduced compute scale and report deviations.

**Freshness/access:** Current 2026 site explicitly links recordings. Some full assignments need substantial GPU compute; learning materials are free.

**Used in:** M14/M17.

## C15 — Multimodal/generative branch

**Primary:** [fast.ai Deep Learning Foundations to Stable Diffusion, part 2](https://course.fast.ai/Lessons/part2.html). [Videos / syllabus](https://course.fast.ai/Lessons/part2.html).

**Before it:** Completed part 1 and strong Python; English videos.

**Do this:** Selected foundations and diffusion lessons; build one evaluated vision/audio/media project, not every modality simultaneously.

**Freshness/access:** Older foundational course; follow current Diffusers and model-specific documentation for execution.

**Used in:** M15.

## C16 — MLOps and deployment

**Primary:** [DataTalksClub MLOps Zoomcamp](https://github.com/DataTalksClub/mlops-zoomcamp). [Videos / syllabus](https://github.com/DataTalksClub/mlops-zoomcamp).

**Before it:** Python, trained ML models, command line and Docker basics; English videos/materials.

**Do this:** Intro → tracking → orchestration → deployment → monitoring → practices → final project.

**Freshness/access:** Repository actively maintained in 2026; recordings may be from earlier cohorts. Use current main syllabus, date your chosen cohort.

**Used in:** M16/M18.

## C17 — RL depth

**Primary:** [Hugging Face Deep RL Course](https://huggingface.co/learn/deep-rl-course/en/unit0/introduction). [Videos / syllabus](https://huggingface.co/learn/deep-rl-course/en/unit0/introduction).

**Before it:** Probability, PyTorch and neural networks; mixed text/video/labs.

**Do this:** MDPs and value methods → policy gradients → PPO. Core ideas support post-training; environment specialization optional.

**Freshness/access:** Official living course, update environment/library compatibility when running.

**Used in:** M13 optional depth.

# Necessary bridges and current documentation

- Calculus bridge: [3Blue1Brown’s Essence of Calculus](https://www.3blue1brown.com/lessons/essence-of-calculus/), then the vector-calculus and optimization exercises in Mathematics for Machine Learning. The search excerpt verifies the introductory video; do not mistake visualization for calculus practice.
- Linear algebra depth: [MIT 18.06 recordings](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/video_galleries/video-lectures/) plus assignments. The course is labeled Spring 2010; the video page says recordings are from 1999. This age is acceptable for linear algebra.
- Data analysis: [Python for Data Analysis, open third edition](https://wesmckinney.com/book/), chapters on NumPy, pandas, cleaning, joining and grouping. Use C07’s Python labs for video accompaniment. This is deliberately a book-led segment, not an invented dedicated video course.
- ML first exposure, if C07 is too steep: [Google’s refreshed ML Crash Course](https://developers.google.com/machine-learning/crash-course). This is a shorter bridge, not a replacement for ISLP’s statistical depth.
- Deep-learning internals: [PyTorch Learn the Basics](https://pytorch.org/tutorials/beginner/basics/intro.html) and D2L. Rebuild a fast.ai project without fastai abstractions.
- Production reading: [Made With ML](https://madewithml.com/) and [Machine Learning Systems](https://mlsysbook.ai/). These are required supplements for systems-oriented depth, not additional entire video playlists.
- Python reference: [official tutorial](https://docs.python.org/3/tutorial/). Its own page says it assumes programming knowledge, so use it after C01 has taught the basics.
- Environment management: [uv official documentation](https://docs.astral.sh/uv/). Learn pip/venv concepts before choosing uv for reproducible projects.

## Order you should actually follow

C01 → C02 → C03/C04 → C05/C06 (with data practice) → C07 → C08 → C09 → C10 → C11 → C12 → C16. Then take C14 for model/systems depth, C15 for multimodal depth and C17 for RL depth. C13 is framework depth after C12. Math can run alongside programming once basic syntax is comfortable. Safety checkpoints apply before public deployment.

Do not start CS336, distributed training, Kubernetes or multi-agent systems in week one. First finish a program you understand end to end. Paid compute, API calls and course certificates are separate from free access to the learning material.
