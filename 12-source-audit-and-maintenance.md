# Sources, coverage and maintenance

Research date: 2026-10-07. Public official course sites, author-hosted books, repositories, framework documentation and arXiv pages were used. Firecrawl was the main collection tool. Source records include direct retrieval, linked references and unsuccessful attempts; the audit does not imply that every URL appearing in the documents was fetched.

The saved-material expansion in documents 15–19 used direct web retrieval of official repositories, paper abstracts and creator-linked courses. [Structured review](data/saved-material-review.json) preserves corrections and unresolved names; [source records](data/source-audit.json) include the additional sources. All 20 corrected project repositories and the eight named frameworks plus LlamaIndex were inspected at README level. Four new paper abstracts were inspected. Videos were verified through author/course links or metadata, not watched end to end; Khan Academy returned no extractable page text. No new benchmark or model-training experiment was run. The original table below describes the earlier pass; the JSON contains the later additions.

## What was verified

- Both user-supplied repositories: outline/README, visible directory scope and selected actual lesson prose.
- Primary course landing pages/syllabi and author-linked recordings, with current 2026 MIT and Stanford offerings distinguished from archived lectures.
- Author statements of legal free access to the listed books; actual PDF/EPUB asset downloads were not tested.
- The titles and abstracts of all 24 selected papers.
- Core framework responsibilities, vector-store documentation, inference documentation and Expo notification/storage capabilities.
- Two example employer role pages, sufficient for role-specific priorities, not a market-wide demand ranking.

## Limits

No claim is made to list all existing tools, master all roles in two years, independently execute all repository lessons, or identify a universally best course. Selection is tailored to your beginner-to-engineering goal. Historic course code may need current API changes. Video geoblocking, future free-access terms, individual notebook execution and GPU/API costs were not fully audited.

The two framework terms QAI/LangRAG remain unresolved. Hindi-specific replacement playlists can be curated if English becomes a learning barrier; none were invented merely to fill a language column. The Android app is specified for later, not implemented. No account actions or notifications were performed.

## Maintenance without chasing every launch

Before each new module: recheck the primary course, current official docs and supported package combinations. Preserve the chosen course edition and model/dataset versions in project notes. Once per quarter, inspect the advanced reading lists and framework migration notices. Keep foundational resources unless there is a concrete pedagogical gap.

Add new resources only with their purpose, prerequisite, source, access status and evidence exercise. Keep an archive of replaced choices so you can explain why the curriculum changed. A new framework name does not automatically create a new required skill.
