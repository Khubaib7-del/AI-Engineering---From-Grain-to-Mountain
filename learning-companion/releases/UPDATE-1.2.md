# Update to AI Learning 1.2

Install the Android 1.2 APK over the existing app. Keep the app installed so Android preserves your local notebook and sign-in. The app package and signing certificate stay the same; version code advances to 3.

This release includes the expanded 21-module curriculum, distinct Learn / Read / Practice resources for each module, direct course links, and the revised self-paced module path. You can open any module after the initial 28 guided sessions. Prerequisites guide study order and gate the final assessment. If a module you already assessed gained new checkpoints, your old assessment stays saved while you complete those additions.

The web version can update independently. The Android curriculum is bundled in the APK, so install this update to get the same content on your phone. Account sync continues to share your progress when you sign in with the same account.

The APK is a development-test-signed personal preview for ARM64 Android 7.0 or later. It is not a Google Play release. Export a notebook backup from Settings before changing devices or clearing app storage.
