# Workspace guide

For a new coding/research session, begin with [AGENTS.md](AGENTS.md). For the learning material, use [README.md](README.md).

| Task | Entry point |
|---|---|
| Understand the learning sequence | `01-roadmap-and-study-system.md`, `02-granular-curriculum.md` |
| Choose courses, books and papers | `03-courses-in-order.md`, `04-free-books.md`, `05-papers-reading-order.md` |
| Understand tools, roles and projects | Documents `06` through `09` |
| Start the first month | `10-first-28-days.md` |
| Find the one resource to study next | `24-guided-free-learning-route.md` |
| Understand the app specification | `11-learning-app-spec.md` |
| Check evidence and source freshness | `12-source-audit-and-maintenance.md` |
| Explore foundations and added depth | Documents `13` through `23` |
| Edit the application | `learning-companion/AGENTS.md` |
| Check current UI direction | `learning-companion/design/MONOCHROME-DIRECTION.md` |
| See validation and limitations | `learning-companion/VALIDATION.md` |
| Find installable packages | `learning-companion/releases/`, once a build succeeds |

Numbered filenames intentionally stay stable: existing citations and the content-sync pipeline depend on them. Structured data, templates, original design attachments, source code and release artifacts have separate directories. Historical design notes remain evidence of prior iterations; current preference is recorded in AGENTS.md.
